# 💡 Telegram 使用技巧

## ① 不要只用 Telegram 自带搜索

推荐组合：

```
Telegram

+

TGStat

+

Telemetr

+

TGNAV

+

极搜
```

搜索效率提升很多。

---

## ② 多尝试英文关键词

例如：

```
AI

Programming

Linux

Movie

News
```

很多资源只有英文名称。

---

## ③ 收藏常用资源

建议建立一个收藏夹：

```
Telegram

├── 搜索网站
├── AI
├── 新闻
├── 学习
├── 软件
└── Bot
```

以后找资源效率会高很多。
